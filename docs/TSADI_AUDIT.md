# אות צ׳ — דוח טיוטות ואימות

- קובץ המקור `data/alphabet/צ.json` מכיל **237 ערכים** ו־**3,224 היקרויות**. המספר 202 שנמסר קודם אינו נכון לגבי הקובץ הנוכחי.
- נכתבו **237 פירושים עבריים ראשוניים** בקובץ `data/tsadi-hebrew-drafts.txt`, והם שולבו ב־JSON.
- הפירושים **לא אומתו** מול Strong/BDB ולא עברו עריכה לשונית מוסמכת. כמה ערכים נדירים או הומוגרפים סומנו בטיוטה כטעונים בדיקה; גם שאר הערכים מחייבים אימות.
- נוסף `scripts/build-tsadi-dictionary.cjs` המבוסס על מנגנון האות ה׳, לבדיקת מקורות לקסיקליים ומיקומי MorphHB.
- **הסקריפט לא הורץ** ולא הוכחה הצלחתו. יש לבדוק התאמות חריגות של Strong/BDB, בדיקות כתיבה ותופעות טוקניזציה לפני הרצה.
- דגלי `editoriallyApproved`, `strongSourceChecked`, `bdbSourceChecked` ו־`occurrenceCountChecked` נשמרו `false`.
- אין להפעיל GitHub CI אוטומטי; בדיקות יתבצעו מקומית ב־MacBook דרך Claude Code.

## המשך עבודה

1. להפעיל סקריפט בדיקה מקומי באופן מבוקר, אחרי בדיקת side effects.
2. לאמת כל אחד מ־237 הערכים מול Strong/BDB ולתקן פירושים שאינם תואמים.
3. לאמת את כל 3,224 ההיקרויות מול MorphHB, כולל מיקומי טוקנים וחריגי קרי/כתיב.
4. לבצע בדיקות רגרסיה לממשק והדגשת המילים.
5. לתעד תוצאות מדויקות ולהעביר לביקורת עריכתית.
