# אות ל׳ — בקרת מילון ומקורות

- **145 ערכים מילוניים**, **8,769 היקרויות**, מתוך **39 ספרי מקרא**.
- לכל 145 הערכים נוסח פירוש עברי ראשוני, נרשמו קטעי המקור המדויקים מ־Strong ונשמרו קטעי BDB בהתאם להפניות ב־LexicalIndex.xml.
- המקורות מוצמדים לגרסאות HebrewLexicon `21c9add13bc727d3a951361778e97e3ff7afd1ce` ו־MorphHB `db6c5c9b46b8f39346f10915ddb1a70dcd429901`.
- בדיקת GitHub Actions עברה: התאמת מזהי הטוקנים, הפסוקים, צורת המילה, הלמה והמורפולוגיה לכל 8,769 ההיקרויות; תוקנו **239 מיקומי טוקנים** לפי סדר המילים בקובצי MorphHB.
- בדיקת הנתונים גם אישרה קיום 145 פירושים עבריים ו־145 קטעי Strong/BDB.
- **לא בוצעה בקרת עריכה אנושית מלאה של הפירושים**. הם טיוטות המבוססות על מקורות מילוניים, ואסור להציגם כמאושרים מבחינה מחקרית. גם שיוך היקרויות למשמעויות ספציפיות לא נבדק ידנית.
- ניתן לשחזר את העיבוד והבדיקות באמצעות `node scripts/build-lamed-dictionary.cjs` עם גישה למקורות המקובעים.

הבדיקות מאמתות התאמה טכנית למקורות, לא נכונות פרשנית מלאה של כל פירוש.
